Car Wash Management System

Aplikasi manajemen operasional transaksi jasa pencucian kendaraan berbasis Java Object-Oriented Programming (OOP) yang menerapkan prinsip clean code dan teknik simple refactoring.

Deskripsi Singkat
Sistem ini memfasilitasi pencatatan data kendaraan konsumen (mobil dan motor), penentuan biaya dasar cuci, kalkulasi diskon otomatis bagi pelanggan member (15%), serta penghitungan pajak layanan (10%) hingga pencetakan nota rincian akhir.

Struktur & Dokumentasi Kode
Proyek ini mengadopsi standar **JavaDoc** pada seluruh kelas dan method:
VehicleInfo: Parameter Object pembungkus identitas kendaraan.
WashService: Superclass penyedia logika kalkulasi diskon, pajak, dan cetak nota.
CarWash & MotorcycleWash: Subclass spesifik jenis layanan.
@param, @return: Pendokumentasian tipe input dan nilai kembalian setiap method.

Persyaratan
JDK 17 atau yang lebih baru
IntelliJ IDEA / NetBeans

Cara Menjalankan
1. Buka folder proyek di IntelliJ IDEA.
2. Buka file CarWashSystem.java.
3. Jalankan method main() melalui shortcut Ctrl + Shift + F10 atau klik tombol Run (Play).
